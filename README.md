# 项目管理投资框架公开页面

这是新版项目管理投资框架的独立 GitHub Pages 发布仓库，与原版页面分开部署，互不覆盖。

发布日期：2026-08-03

来源提交：`fb0dc5e`

- `index.html`：以公司为主语的项目管理投资研究工作台
- `practice.html`：带判断复查履历的项目管理投资框架练习册

本版进一步补全三个项目管理概念：范围管理中的需求重要程度与紧急程度，进度管理中的里程碑、检查节点和进度偏差，以及风险管理中的识别、定性、定量、应对和监督。十领域只评价公司怎样管理及其经营偏差，个人仓位和买卖仍放在独立执行层。

页面为离线单文件，不依赖远程脚本、字体或图片。
